Sistemas Difusos (Fuzzy Logic)

Cómo una computadora puede razonar con conceptos imprecisos como "algo frío" o "bastante caluroso", usando el control de velocidad de un ventilador inteligente como caso de estudio.

Introducción Fuzzificación Reglas Inferencia Defuzzificación Código Python
i

¿Por qué lógica difusa?

Un termostato binario tradicional se enciende o apaga de golpe al cruzar un valor fijo, por ejemplo a 24°C. Un sistema difuso (fuzzy system) en cambio permite ajustar la salida de forma suave y gradual, imitando cómo razonamos los humanos con categorías imprecisas: "está un poco caluroso", "hace bastante frío", etc.

El flujo estándar de todo sistema difuso tiene tres etapas:

Fuzzificación
→
Inferencia
→
Defuzzificación

Caso de estudio: control de velocidad de un ventilador inteligente según la temperatura ambiente.

1

Variables y conjuntos difusos (Fuzzificación)

Convertimos lecturas numéricas exactas en términos lingüísticos, usando grados de pertenencia entre 0 y 1 (a diferencia de la lógica clásica, donde algo es 100% verdadero o 100% falso).

Entrada — Temperatura (°C):

Fría — alta si T < 18°C Templada — alta cerca de 22°C Calurosa — alta si T > 26°C

Salida — Velocidad del motor (%):

Lenta (20%) Media (50%) Rápida (90%)
Una misma temperatura puede pertenecer parcialmente a dos categorías a la vez — por ejemplo, 24°C puede ser "un poco templada" y "un poco calurosa" simultáneamente. Esa es la clave de la lógica difusa.
2

Base de reglas (IF–THEN)

La lógica se define con reglas de sentido común o conocimiento experto:

#Condición (SI)Conclusión (ENTONCES)
1Temperatura es FríaVelocidad es Lenta
2Temperatura es TempladaVelocidad es Media
3Temperatura es CalurosaVelocidad es Rápida
3

Inferencia con un caso real

Supongamos que el sensor mide 24°C. Ese valor cae en una zona de transición entre dos categorías:

Pertenece a Fríaμ = 0.0
Pertenece a Templadaμ = 0.6
Pertenece a Calurosaμ = 0.4

Las reglas activadas son:

  • Regla 2 (Templada → Media): se activa con fuerza 0.6
  • Regla 3 (Calurosa → Rápida): se activa con fuerza 0.4
4

Defuzzificación (salida numérica)

Combinamos los resultados de las reglas activadas para obtener un único valor numérico, usando por ejemplo el método del promedio ponderado:

Velocidad = ( 0.6 × 50% + 0.4 × 90% ) ÷ ( 0.6 + 0.4 )
Velocidad = ( 30 + 36 ) ÷ 1.0
Velocidad final: 66%

El ventilador no salta bruscamente entre niveles fijos: opera de forma suave al 66% de su capacidad, combinando proporcionalmente las reglas "templada" y "calurosa".

5

Implementación en Python (scikit-fuzzy)

La librería scikit-fuzzy permite construir este mismo sistema de forma directa: se definen las variables, las funciones de pertenencia, las reglas, y la librería se encarga de la fuzzificación, inferencia y defuzzificación automáticamente.

python 
import numpy as np
import skfuzzy as fuzz
from skfuzzy import control as ctrl

# 1. Definir las variables de entrada y salida (universos de discurso)
temp = ctrl.Antecedent(np.arange(10, 41, 1), 'temperatura')
fan  = ctrl.Consequent(np.arange(0, 101, 1), 'velocidad')

# 2. Funciones de pertenencia triangulares
temp['fria']     = fuzz.trimf(temp.universe, [10, 10, 22])
temp['templada'] = fuzz.trimf(temp.universe, [18, 22, 26])
temp['calurosa'] = fuzz.trimf(temp.universe, [22, 40, 40])

fan['lenta']  = fuzz.trimf(fan.universe, [0, 0, 50])
fan['media']  = fuzz.trimf(fan.universe, [20, 50, 80])
fan['rapida'] = fuzz.trimf(fan.universe, [50, 100, 100])

# 3. Base de reglas IF-THEN
regla1 = ctrl.Rule(temp['fria'],     fan['lenta'])
regla2 = ctrl.Rule(temp['templada'], fan['media'])
regla3 = ctrl.Rule(temp['calurosa'], fan['rapida'])

# 4. Construir el sistema de control y simularlo
sistema    = ctrl.ControlSystem([regla1, regla2, regla3])
simulador  = ctrl.ControlSystemSimulation(sistema)

# 5. Ejecutar con el caso real: 24°C
simulador.input['temperatura'] = 24
simulador.compute()

print(f"Velocidad calculada: {simulador.output['velocidad']:.1f}%")
# Salida esperada: Velocidad calculada: 66.0%
Para el alumno: prueba cambiar el valor de simulador.input['temperatura'] por otros números (por ejemplo 15, 20 o 35) y observa cómo la velocidad de salida cambia de forma suave y continua, sin saltos bruscos. También puedes agregar fan.view(sim=simulador) al final para graficar la función de pertenencia activada.
